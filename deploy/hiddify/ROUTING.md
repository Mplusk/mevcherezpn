# Российские сайты напрямую

Правила маршрутизации применяются на устройстве: сайты из списка прямого доступа видят обычный IP вашей сети, а остальные запросы направляются через выбранный VPN-сервер. Списки не могут точно определить все российские сайты и приложения.

## Hiddify

Hiddify использует собственные правила маршрутизации и не применяет произвольные правила из подписки. Для Hiddify 5.9.15 включите встроенный обход на каждом устройстве:

1. Откройте **Настройки → Маршрутизация** и выберите **Регион → Россия (ru)**.
2. Найдите встроенное правило **Обход сайтов региона Россия (ru)** и убедитесь, что оно включено. Название может немного отличаться в другой версии приложения.
3. Отключите VPN и подключите его снова.

Встроенный список Hiddify отличается от списка runetfreedom и не гарантирует обход для всех российских ресурсов. На Android правила сайтов не обязательно исключают само банковское приложение из VPN; автоисключение приложений по региону также имеет [известное ограничение](https://github.com/hiddify/hiddify-app/issues/2664). При необходимости проверьте отдельную настройку **Маршрутизация по приложениям**.

## Happ

Если поставщик передаёт профиль маршрутизации вместе с подпиской, обновите подписку и дождитесь загрузки геофайлов, затем отключите и снова включите соединение. При ошибке загрузки геофайлов приложение показывает предупреждение; наличие ссылки в подписке само по себе не подтверждает успешное применение правил. В некоторых версиях Happ настройки профиля зависят от формата подписки. Подробности — в [документации Happ](https://www.happ.su/main/ru/dev-docs/routing).

## Как проверить

1. В одной и той же сети с выключенным VPN запишите свой публичный IP на [Яндекс Интернетометре](https://yandex.ru/internet/).
2. Включите VPN, снова откройте Интернетометр и обновите страницу. Если для него сработал прямой маршрут, IP должен совпадать с записанным; мобильный оператор может изменить его между проверками.
3. При включённом VPN откройте [ipinfo.io](https://ipinfo.io/) и сравните внешний IP с адресом сервера в выбранной стране. Не публикуйте снимки с вашим домашним IP и ссылкой подписки.

Проверка одного сайта не подтверждает маршрутизацию всех остальных. На узлах есть серверная блокировка российских направлений: если клиент не направил российский сайт напрямую, сайт может не открыться. Сервер не может перенаправить такой запрос обратно через интернет устройства.
