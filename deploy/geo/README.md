# Публичные геоданные для маршрутизации

Служба скачивает по HTTPS только фиксированные официальные адреса
`raw.githubusercontent.com/runetfreedom/russia-v2ray-rules-dat/release/geoip.dat`
и `.../geosite.dat`, проверяет формат и минимизирует файлы через `reduce.py`.
Источники и исходный проект распространяются по лицензии
[GPL-3.0](https://github.com/runetfreedom/russia-v2ray-rules-dat/blob/main/LICENSE).
При перераспространении соблюдайте условия этой лицензии.

Файлы передаются через stdin в существующий контейнер `gamelife-gateway-proxy-1`.
Два файла проходят проверку SHA-256 и хранятся в
`/data/public-geodata/revisions/<revision>/`. После проверки ссылка
`/data/public-geodata/current` атомарно переключается на готовую версию;
поддерживается до семи ревизий. Ошибки скачивания, обработки или проверки
оставляют предыдущую версию доступной. SHA-256 удостоверяет неизменность
при передаче и хранении, но не является независимой подписью источника.
Отдельные HTTP-запросы двух файлов могут попасть на разные ревизии при
одновременном обновлении. Данные публичные, секретов и URL подписок нет.
Новые входящие порты служба не открывает. Caddy должен отдельно выдавать
только два нужных пути с корнем `/data/public-geodata/current`.

## Установка и проверка

Запускать от root на VPS, где работает целевой gateway:

```sh
sh deploy/geo/install.sh
systemctl start gamelife-geodata.service
systemctl status gamelife-geodata.service gamelife-geodata.timer --no-pager
systemctl list-timers gamelife-geodata.timer --all --no-pager
journalctl -u gamelife-geodata.service -n 30 --no-pager
```

Таймер запускает проверку каждые шесть часов в 03:17, 09:17, 15:17 и
21:17 UTC с дополнительной случайной задержкой до пяти минут. Пропущенный
запуск выполняется после восстановления системы. Установка включает таймер;
первый немедленный запуск выполняется указанной выше командой `start`.
Docker и сеть должны быть доступны. Если обновление завершилось ошибкой,
журнал покажет тип ошибки, а прежние файлы останутся. Уведомлений о сбоях
само обновление не отправляет; проверять актуальность нужно отдельно.

Файлы `update.py` и `reduce.py` устанавливаются в `/opt/gamelife-geodata`,
а unit-файлы — в `/etc/systemd/system`. Для повторной установки из новой
версии проекта запустите тот же `install.sh`; это обновит код и таймер.
